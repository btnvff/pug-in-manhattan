# Мопс на Манхэттене

Аркада в браузере: мопс ловит еду на нью-йоркской улице, ты двигаешь его пальцем.
Чистый HTML + JS + Canvas 2D, без сборки и зависимостей.

- Играть: открыть `index.html` в браузере (или ссылка на GitHub Pages).
- Как устроен код и правила для разработки: см. [PROJECT.md](PROJECT.md).
